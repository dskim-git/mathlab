# 활동 성찰 유형 설계 메모

작성일: 2026-05-22  
관련 프로젝트: MathLab 수학 웹앱 리뉴얼  
관련 문서: `docs/mathlab_renewal_development_plan_v1.md`

---

## 1. 메모 목적

MathLab의 장기 목표는 각 미니활동에서 학생의 활동 결과와 성찰 자료를 수집하고, 이를 바탕으로 교사가 학생별 학습 기록을 확인하며, 최종적으로 생성형 AI를 활용해 세부능력 및 특기사항 참고 문구 초안을 작성할 수 있게 하는 것이다.

이를 위해 앞으로 미니활동을 만들 때는 활동마다 성찰 입력 방식을 선택할 수 있도록 설계한다.

---

## 2. 성찰 유형 구분

미니활동은 기본적으로 다음 두 가지 성찰 유형 중 하나를 선택해 제작한다.

```text
1. 간단 성찰형
2. 심화 성찰형
```

---

## 3. 간단 성찰형

### 3.1 목적

수업 중 빠르게 활동을 마무리하고 학생의 핵심 생각을 짧게 수집하는 방식이다.

### 3.2 구조

```text
해석 관점 1개 선택
+ 자유 서술형 성찰 1개 작성
```

예시:

```text
해석 관점:
- 시뮬레이션 결과와 이론값 비교
- 반복 횟수와 큰 수의 법칙 관점
- 분포 모양 관찰
- 새롭게 생긴 궁금증

성찰 입력:
- 학생이 선택한 관점에 대해 한 문단으로 작성
```

### 3.3 장점

- 학생 부담이 작다.
- 수업 중 짧은 시간에 제출하기 좋다.
- 응답 저장 구조가 단순하다.
- 여러 미니활동에 공통으로 적용하기 쉽다.

### 3.4 적합한 활동

- 5~15분짜리 짧은 미니활동
- 개념 도입 활동
- 단원 중간 확인 활동
- 실험 결과를 간단히 해석하는 활동
- 학생 전체가 빠르게 참여해야 하는 활동

### 3.5 저장 구조 예시

```json
{
  "activitySlug": "probability-simulator",
  "reflectionType": "simple",
  "interpretationType": "theory_comparison",
  "mode": "coin",
  "n": 30,
  "repeats": 1000,
  "p": 0.5,
  "observedMean": 14.96,
  "expectedMean": 15
}
```

`responses.reflection`에는 학생의 자유 서술형 성찰 1개를 저장한다.

---

## 4. 심화 성찰형

### 4.1 목적

하나의 활동을 통해 학생의 탐구 과정, 개념 이해, 결과 해석, 추가 질문을 더 풍부하게 수집하는 방식이다.

### 4.2 구조

```text
여러 성찰 문항에 각각 답변
```

예시:

```text
1. 실험 결과를 한 문장으로 요약해 보세요.
2. 이론값과 시뮬레이션 결과는 어떤 점에서 비슷하거나 달랐나요?
3. 반복 횟수를 바꾸면 결과가 어떻게 달라졌나요?
4. 이번 활동을 통해 새롭게 알게 된 점은 무엇인가요?
5. 더 탐구해 보고 싶은 질문은 무엇인가요?
```

### 4.3 장점

- 학생의 사고 과정을 더 구체적으로 확인할 수 있다.
- AI 세특 참고 문구 생성에 사용할 근거 자료가 풍부해진다.
- 학생별 탐구 성향, 해석 방식, 질문 생성 능력을 파악하기 좋다.

### 4.4 단점

- 학생 입력 부담이 커진다.
- 수업 시간이 더 필요하다.
- 응답 화면과 저장 구조가 복잡해진다.

### 4.5 적합한 활동

- 20분 이상 진행하는 탐구형 활동
- 수행평가 또는 프로젝트형 활동
- 통계 포스터, 시뮬레이션 탐구, 수학 모델링 활동
- 학생별 기록을 세특 참고자료로 적극 활용하려는 활동

### 4.6 저장 구조 예시

```json
{
  "activitySlug": "probability-simulator",
  "reflectionType": "deep",
  "mode": "coin",
  "n": 30,
  "repeats": 3000,
  "p": 0.5,
  "observedMean": 15.02,
  "expectedMean": 15,
  "reflections": {
    "summary": "동전을 30번 던지는 실험을 3000번 반복했을 때 성공 횟수가 15 근처에 많이 모였다.",
    "theoryComparison": "시뮬레이션 평균이 이론 평균 15와 거의 비슷했다.",
    "largeNumberLaw": "반복 횟수를 늘릴수록 평균이 이론값에 가까워지는 경향이 있었다.",
    "newLearning": "확률은 한 번의 결과가 아니라 반복했을 때의 경향으로 이해해야 한다는 점을 알게 되었다.",
    "question": "성공확률이 0.5가 아닐 때 분포 모양이 얼마나 달라지는지 더 알고 싶다."
  }
}
```

## 5. 활동 제작 시 선택 규칙

앞으로 새 미니활동을 만들 때 활동 메타데이터에 성찰 유형을 포함한다.

예시:

```ts
export const activityMeta = {
  slug: "probability-simulator",
  title: "확률 시뮬레이터",
  subject: "probability",
  activityType: "simulation",
  reflectionType: "simple",
};
```

심화 활동은 다음처럼 설정한다.

```ts
export const activityMeta = {
  slug: "sampling-distribution-deep",
  title: "표본평균 분포 탐구",
  subject: "statistics",
  activityType: "inquiry",
  reflectionType: "deep",
};
```

## 6. 장기 개발 방향

### 6.1 MVP 단계

- 확률 시뮬레이터는 간단 성찰형으로 유지한다.
- `interpretationType` 1개와 `reflection` 1개를 저장한다.
- 응답 저장과 교사용 조회 기능을 먼저 안정화한다.

### 6.2 활동 확장 단계

- 새 미니활동을 만들 때 간단 성찰형 또는 심화 성찰형을 선택할 수 있게 한다.
- 활동 제작 템플릿에 `reflectionType`을 포함한다.
- 심화 성찰형 활동용 공통 컴포넌트를 만든다.

### 6.3 AI 세특 문구 생성 단계

- 간단 성찰형 응답은 핵심 활동 기록으로 사용한다.
- 심화 성찰형 응답은 세특 문구 생성의 주요 근거 자료로 사용한다.
- AI가 문구를 생성할 때 어떤 응답을 근거로 사용했는지 교사가 확인할 수 있어야 한다.
- AI 결과는 반드시 교사가 검토·수정하는 초안으로 취급한다.

---

## 7. 현재 결론

앞으로 MathLab의 미니활동은 단순한 화면 기능이 아니라, 학생의 학습 흔적을 수집하는 단위로 설계한다.

따라서 각 미니활동은 다음 중 하나의 성찰 유형을 가진다.

```text
간단 성찰형:
- 관점 1개 선택
- 성찰 1개 작성
- 빠른 수업용

심화 성찰형:
- 여러 문항에 각각 답변
- 탐구 기록 및 세특 참고자료용
```

이 원칙을 이후 기존 Streamlit 활동을 새 Next.js 앱으로 이식할 때 적용한다.
